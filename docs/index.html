Começar

Rode localmente em minutos

Cinco passos até o app no ar.

Instale as dependências: npm install --legacy-peer-deps
Copie o ambiente: cp .env.example .env e preencha DATABASE_URL
Suba um PostgreSQL (Docker) ou o banco embutido: npm run db:start
Crie as tabelas: npx drizzle-kit push
Inicie o app: npm run dev → localhost:3000

Dúvidas

Perguntas frequentes

O essencial antes de começar.

O que é o Doutor Agenda?

Uma plataforma SaaS de gestão para clínicas e consultórios: cadastro de médicos e pacientes, agendamento de consultas, dashboard com métricas e faturamento, autenticação e planos de assinatura.

Preciso de cartão de crédito para testar?

Não. Você cria a conta com e-mail e senha e já usa o sistema. O Stripe e o login com Google são opcionais e ficam desativados enquanto as chaves não forem configuradas.

Consigo rodar no meu computador?

Sim. Basta Node.js e um PostgreSQL (ou o banco embutido PGlite). Siga os cinco passos da seção "Como rodar" acima.

O app roda nesta página do GitHub Pages?

Não. O Doutor Agenda é server-side (autenticação e banco de dados) e o GitHub Pages serve apenas conteúdo estático — por isso esta é a página de apresentação. Para hospedar o app completo, use uma plataforma com backend, como a Vercel.

Quais tecnologias são usadas?

Next.js 15 (App Router) e React 19, TypeScript, Tailwind CSS + shadcn/ui, Drizzle ORM com PostgreSQL, Better Auth, next-safe-action, Zod, Stripe e Recharts.
