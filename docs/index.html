Como rodar localmente

Em poucos passos você tem o app rodando.

Instale as dependências: npm install --legacy-peer-deps
Copie as variáveis: cp .env.example .env e preencha DATABASE_URL
Suba um PostgreSQL (Docker) ou o banco embutido: npm run db:start
Crie as tabelas: npx drizzle-kit push
Inicie o app: npm run dev → http://localhost:3000
⚠️ Sobre esta página: o Doutor Agenda é uma aplicação server-side (autenticação e banco de dados), então não roda no GitHub Pages — esta é apenas a página de apresentação. Para hospedar o app completo, use uma plataforma com backend, como a Vercel.
